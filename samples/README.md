# Samples

Showcase content seeded into an empty collection. GLB files are stored with Git LFS.

| File | What it is |
|---|---|
| `models/eagle-web.glb` | The eagle scan after post-processing and meshopt compression: 300 k triangles, 2.2 MB. Also what the demo pipeline publishes |
| `models/eagle-dense.ply` | The same scan as COLMAP's raw Poisson mesh: 3.2 M triangles, not upright |
| `models/eagle.glb` | The raw mesh exported from Blender (90.7 MB), kept for comparison |
| `models/DamagedHelmet.glb` | Khronos glTF sample asset for checking materials and lighting (see licence in the root README) |
| `thumbnails/*.webp` | Covers captured with the viewer |
